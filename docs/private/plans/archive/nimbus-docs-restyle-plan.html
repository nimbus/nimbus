Architecture

The content seam does not move. The renderer under website/ is replaced, and every mark consumer reads the one mascot drawing.

Scope

Owns: the mascot mark on every Nimbus surface (console tokens and component, desktop icons and setup card, README banner, Odyssey nav), the replacement of the Starlight renderer under website/ with a static Next and fumadocs export themed on the console palette, the Odyssey homepage on /, the fold of the old splash content into the docs landing, and the rewrite of the docs gates, workflow, deploy config, docs skill, and DESIGN.md §Documentation Site that describe the site.

Does not own: the Markdown content under docs/ (the docs skill owns it; pages move only where a route changes), the console shell beyond the mascot (archived nimbus-ui-rebuild-plan.html), and the marketing repositories under nimbus-marketing-2026-09-11, which stay as the source the port copies from and are not edited.

Non-goals: server-rendered docs, a Cloudflare Worker runtime, i18n, a redesign of the Odyssey narrative or its scenes, and any change to the console accent tokens. The accent stays #b45309 on light grounds for its contrast floor; only the mark keeps gold.

Invariants

  1. No file under docs/private/ and no string "open source" reaches the built site, the llms files, or the deploy artifact.
  2. The six published groups stay the only docs content source. The renderer reads them from docs/; it never carries a copy.
  3. The mark is one drawing. Body --mark, face --mark-ink; gold #f0b23e / #1a1204 on light grounds, white #f6f7f8 / #18181b on dark grounds. No outline variant and no accent fill.
  4. The deploy stays Cloudflare static assets under the existing nimbus-docs worker name and custom domains. No server runtime.
  5. Every published URL that existed on the Starlight site either still resolves or is listed in the DR7 proof with its replacement.
  6. Both scripts/check-docs.sh and scripts/verify-nimbus-docs-site.sh pass on the final tree, and the verify script keeps a fixed condition count with the Summary: N passed, M failed shape.
  7. Published copy follows the docs skill messaging canon and never introduces a claim that is not in it.
