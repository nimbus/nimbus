Nimbus UI rebuild plan

Status: active · Owner: this plan · Created: 2026-09-08 · Baseline: main @ 67a7f3ffa · Proof root: proof/nimbus-ui-rebuild/ · Pull requests: #331 (Phase 1, UIR0–UIR4, open) · #332 (Phase 2, UIR5–UIR8, open) · #333 (Phase 3, UIR9–UIR16, open) · Next action: UIR24 cleanup when the Phase 4 pull request #334 merges (stack: #331, #332, #333, #334)

Outcome

The operator console at packages/nimbus-ui runs on the Starport console stack (shadcn base-nova on Base UI, TanStack Router, Table, Virtual, and Charts) with one neutral-plus-amber palette in light and dark, Geist Sans for labels and Geist Mono for data, one sidebar that owns the Developer and Operator scope, a resizable sub-panel only where a page lists data, the Nimbus cloud as a face-only mascot mark, and every page rebuilt in place with its specs and end-to-end tests green. The thirteen findings of the 2026-09-08 design review are closed, and the four capability gaps (onboarding, observability, storage editors, Files, Sandboxes, and Deploys) ship behind named server contracts. The reactive @nimbus/nimbus/react data layer, the codegen pipeline, and the embedded /ui/* delivery do not change.

Progress

Architecture

The data layer stays the same in both views: routes call useQuery(api.x, args) from @nimbus/nimbus/react over the /convex WebSocket, and writes go through lib/api-mutations.ts. The plan replaces the visual system, the shell, and the page compositions, and it adds server contracts only where a gap task names one.

Scope

Owns: everything under packages/nimbus-ui (tokens, primitives, shell, routes, specs, stories, end-to-end tests, fonts, favicon, mascot), the design-review findings F1 through F13, and the five server contracts that the gap tasks name (function error class, tenant-scoped run logs and spans, error fingerprint, schema apply and index build status, sandbox exec stream, deploy history and rollback).

Does not own: release packaging of the embedded UI (distribution-plan.md); secret CRUD screens (secret-management-plan.md S12, which consumes this shell); sandbox backend behavior (nimbus-sandbox-plan.md); the closed Band UI hygiene rows in architecture-review-2026-07-plan.md, which stay as history.

Non-goals: a marketing site or docs theme; TanStack Query (the reactive SDK is the cache); a mobile-first redesign beyond the <640px sheet layout; a component library published outside this package; compatibility shims for the old palette keys or drawer state (pre-launch: delete them).

Invariants

  1. Pre-launch rules apply: breaking changes, no compatibility shims, no feature flags for the old shell, delete old localStorage keys.
  2. @nimbus/nimbus/react stays the only data layer. No TanStack Query. Writes go through lib/api-mutations.ts.
  3. npm run codegen, npm run typecheck, npm run test, npm run build, and npm run test:e2e:smoke pass at the end of every task. make check still embeds packages/nimbus-ui/dist.
  4. One accent, four jobs. Semantic colors (ok, warn, error) never use the accent hue. Mono is the voice of data, never of labels.
  5. Every shadcn primitive is installed by the CLI into src/components/ui and is not hand-edited except through a recorded reason in the proof root.
  6. Every route keeps its spec file, and every rebuilt page adds or updates a Storybook story only if the component is Nimbus-owned.
  7. A server contract change lands with its Rust tests and its console consumer in the same task, and it reads docs/private/adapters/convex/ai-guidelines.md first when it touches the Convex surface.
  8. Each phase ends with autoreview --gate pre-pr --mode auto before its pull request.
