# Storage Integrity Contracts Proof

This directory holds evidence for
`docs/private/plans/archive/storage-integrity-contracts-plan.md`, archived
2026-08-19 after pull requests #281-#290 merged. It is retained because Nimbus
keeps completed campaign evidence.

Each task writes one proof file named after its lowercase task ID. SIC0 adds
the fixed 13-condition `verify.sh` and records the red baseline. Raw data and
rejected runs stay separate from verdict files.
