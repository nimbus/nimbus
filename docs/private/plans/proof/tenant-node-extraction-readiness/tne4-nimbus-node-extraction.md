## Implementation

- Added `crates/nimbus-node` as the owner of node-local enforcement:
  - `LocalEnforcementBinding`
  - `TenantWorkloadSpec`
  - `TenantWorkloadStatus`
  - node status authorization
  - credential projection authorization
  - host lifecycle abstractions
  - direct-process backend
  - systemd transient backend
  - `NodeWorkloadReconciler`
  - `StatusEvidenceWriter`
- Converted `crates/nimbus-server/src/local_enforcement.rs` into an intentional
  shim:

  ```rust
  pub use nimbus_node::*;
  ```

- Kept server-owned `_nimbus` persistence in
  `crates/nimbus-server/src/system_tenant/records.rs`.
  `SystemTenantStatusEvidenceWriter` remains the concrete server
  implementation of the `nimbus-node` writer trait.
- Did not move server transport, adapters, storage providers, system-tenant
  persistence, or control-plane replication internals into `nimbus-node`.

- **REQ-NODE-CRATE:** normal dependency tree for `nimbus-node` is limited to

- **REQ-HOST:** moved tests still prove direct-process and systemd transient
  backends validate/start/stop/inspect through typed requests. TNE3 reconciler
  tests now run in `nimbus-node`.

  `_nimbus` writes. `nimbus-node` owns only `StatusEvidenceWriter` and

  misuse, and desired-state mutation targets.

  redaction metadata, and subject echo-back.

  names are sanitized, raw systemd properties are allowlisted, and trusted
