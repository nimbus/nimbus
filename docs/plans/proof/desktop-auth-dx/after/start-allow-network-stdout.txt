# DA9 proof — network-bind guardrails (NB1 + NB2)

Captured 2026-05-20 against the debug build at target/debug/nimbus.

## `nimbus start --help` advertises the `--allow-network` opt-in

$ nimbus start --help | grep -A2 'allow-network\|--host '
      --host <HOST>
          Host interface to listen on. Defaults to loopback for local safety

      --allow-network
          Opt-in to binding on a non-loopback interface. Without this flag, `nimbus start` refuses any `--host` that resolves outside the loopback range. With the flag set, the daemon additionally requires that the local admin token has been rotated within the staleness window (see `nimbus auth rotate-admin`).

The matrix verifies:
  - Loopback hosts (127.0.0.1, ::1, localhost) bypass the gate.
  - Non-loopback bind without --allow-network exits with the refusal +
    opt-in hint message.
  - Non-loopback bind with --allow-network and a never-rotated admin
    token exits with the tripwire pointing at `nimbus auth rotate-admin`.
  - Non-loopback bind with --allow-network and a stale rotated_at also
    trips, with the same hint.
  - Non-loopback bind with --allow-network and a fresh rotated_at is
    allowed to proceed.
