# DA8 proof — `nimbus auth login` / `status` / `logout` round-trip

Captured 2026-05-20 against the debug build at target/debug/nimbus
with a sandboxed `$HOME` and `$XDG_CONFIG_HOME` so the credentials
file is created from scratch.

## Empty status (no stored bearers)

$ nimbus auth status
Credentials file: /tmp/nimbus-da8-proof/home/.config/nimbus/credentials
No stored deploy bearers. Use `nimbus auth login --url <daemon> --bearer <value>` to add one.

## Login adds a bearer, status lists it masked

$ nimbus auth login --url https://nimbus.example.com --bearer deploy_tok_abcdef0123456789
Stored bearer for https://nimbus.example.com (mask: deploy_tok_…6789)
Credentials file: /tmp/nimbus-da8-proof/home/.config/nimbus/credentials

$ nimbus auth status
Credentials file: /tmp/nimbus-da8-proof/home/.config/nimbus/credentials

  https://nimbus.example.com
    bearer:       deploy_tok_…6789

## Add a second connection, status lists both

$ nimbus auth login --url http://localhost:3210 --bearer deploy_tok_local_dev_99887766
Stored bearer for http://localhost:3210 (mask: deploy_tok_local_dev_…7766)
Credentials file: /tmp/nimbus-da8-proof/home/.config/nimbus/credentials

$ nimbus auth status
Credentials file: /tmp/nimbus-da8-proof/home/.config/nimbus/credentials

  http://localhost:3210
    bearer:       deploy_tok_local_dev_…7766
  https://nimbus.example.com
    bearer:       deploy_tok_…6789

## Logout removes one entry, status confirms

$ nimbus auth logout --url http://localhost:3210
Removed bearer for http://localhost:3210

$ nimbus auth status

  https://nimbus.example.com
    bearer:       deploy_tok_…6789
